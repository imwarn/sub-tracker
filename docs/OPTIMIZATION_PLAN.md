# Sub-Tracker 优化实施方案与技术规范

## 1. 目标与设计原则

* **零额外运维**：保持单 Cloudflare Worker + KV 架构，所有改动不引入额外付费服务或外部重型依赖。
* **渐进式迭代**：分阶段落地，每阶段独立包含功能开发、UI 适配、测试用例与构建验证。
* **数据向后兼容**：不破坏已有 KV 数据格式，平滑升级。

## 3. 技术设计规范

### 3.1 eSIM LPA 二维码生成
* **GSMA LPA 规范**：`LPA:1$<SM-DP+ Address>$<Activation Code>[$<Confirmation Code>]`
* **实现方案**：内嵌轻量级纯 JS 二维码生成模块（零外部网络加载，离线 PWA 可用），在卡片上提供“二维码”快捷入口，点击弹出居中二维码模态框。

### 3.2 敏感信息脱敏与复制交互
* **展示形式**：`form-activation-code`、`form-confirmation-code` 以及卡片上的代码信息支持一键切换显示/隐藏。
* **快捷复制**：提供“复制 SM-DP+”、“复制激活码”、“复制完整 LPA 串”按钮，并弹出 Toast 提示。

### 3.3 IP 级别 OTP 频次限制
* **存储键**：`auth_ip_cooldown_<ip>` (TTL 60s) 与 `auth_ip_count_<ip>` (TTL 300s，上限 5 次)。
* **防御效果**：避免暴力扫描、刷爆 TG Bot 配额或对 Bark 推送产生骚扰。

### 3.4 订阅自动续订 (Cron 自动触发)
* **执行时机**：每日 Cron 触发时，遍历 `subscription` 且 `autoRenew === true` 且 `status === 'active'` 的条目。
* **顺延逻辑**：若今天达到或超过 `expireDate`，按其 `billing` 周期（月/年/固定天数）自动顺延，并记录 `action: 'renew', details: { auto: true }` 到操作历史，同时发送通知。

### 3.5 多币种汇率折算
* **基准货币**：支持在常数或设置中指定主币种（如 CNY / USD）。
* **汇率配置**：内置主流货币基准参考汇率字典（USD, EUR, GBP, JPY, HKD, TWD, KRW, TRY, THB, NGN, INR, PHP, MYR, SGD），并支持用户自定义覆盖。
* **聚合面板**：在月度支出与分析面板中，计算“折算总月度支出”与“折算总年度支出”。

## 4. 验证与验收标准

1. `npm test` 全部通过，覆盖所有新增逻辑（LPA 二维码数据串、IP 限流、自动续期、汇率折算）。
2. `npm run build` 打包构建成功，`worker/worker.js` 无语法及打包错误。
3. 移动端与桌面端均能正常完成增删改查、二维码查看、自动续费和多币种汇总。
