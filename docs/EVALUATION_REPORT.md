# Sub-Tracker 系统全维度评估报告

**评估时间**：2026-08
**项目名称**：Sub-Tracker (eSIM 保号 & 订阅费用管理看板)
**技术架构**：Cloudflare Workers + Cloudflare KV + Cron Triggers + 原生 HTML/TailwindCSS CDN

---

## 1. 架构与产品现状评估

### 1.1 核心优势
1. **边缘计算与零成本运行**：利用 Cloudflare Workers 全球边缘节点与免费 KV 存储（100k 读/天），实现零服务器、零冷启动的低成本部署。
2. **场景整合度高**：将国际 eSIM 保号卡（周期续期与国码识别）、互联网订阅服务（按月/年计费与多币种）、国内/海外电话卡话费（月租扣除与停机日推算）三大个人资产痛点统一管理。
3. **无密码 OTP 多渠道告警**：基于 Telegram、Bark、企业微信、通用 Webhook 发送 6 位动态验证码与每日到期提醒，保障安全与私密性。

### 1.2 现存局限与改进空间

| 维度 | 现状表现 | 痛点 / 风险 | 优化目标 |
| :--- | :--- | :--- | :--- |
| **eSIM 管理** | 仅记录 SM-DP+ 与激活码纯文本 | 换机或给 iPad 添加 eSIM 时无法直接扫码；敏感激活码缺乏脱敏与一键复制 | 增加标准 LPA 二维码生成、敏感信息脱敏与一键复制 |
| **多币种统计** | 按币种分别分组展示（USD、TRY、CNY 各算各的） | 跨境订阅总支出无法汇总，看板统计数字分散（显示为 `¥120 +`） | 支持本位币设置与汇率折算，展示全币种折算总月/年支出 |
| **订阅自动化** | `autoRenew` 字段仅作标记，到期仍需手动点“续期” | 自动扣费的订阅仍需人工维护到期日，增加用户负担 | Cron 每日检测自动扣款订阅，到期自动顺延并记录历史与通知 |
| **UI 与交互** | 卡片平铺 5~6 个操作图标，移动端触控密集易误触；固定深色主题 | 移动端单手操作不便；户外强光下深色低对比度可读性弱；日历无未来循环投影 | 操作分层收纳、移动端悬浮操作按钮 (FAB)、主题适配、日历未来投影 |
| **安全性** | OTP 仅做了 60 秒全局冷却 | 未做 IP 维度的限流，若接口泄露可能被恶意调用刷通知 | 增加基于 `cf-connecting-ip` 的客户端频次限制 |
| **测试与质量** | 单元测试中存在对自然月续期的计算断言偏差 | `npm test` 存在失败项 | 修复测试断言，补全核心功能测试用例 |

## 2. 详细评估分析

### 2.1 UI / UX 界面与交互

1. **操作密度与防误触**：
   - 当前卡片视图底部横向排列了：充值/续期、启用/暂停、测试通知、编辑、删除等按钮。
   - 在手机端，由于触控区域较小且排列紧凑，用户点击“编辑”或“续期”时容易误触“删除”或“测试通知”。
2. **日历视图生命力不足**：
   - 当前日历仅根据数据库中现有的静态 `expireDate` 绘制。
   - 切换到下月时，按月续费的常规订阅不会在下月日历中出现，无法帮助用户预估下月现金流。
3. **移动端单手操作支持**：
   - 列表较长时，新增条目需滑至顶部。增加右下角 FAB（浮动操作按钮）能显著提升移动端操作流畅度。

### 2.2 核心业务功能

1. **eSIM 实用性（LPA 二维码）**：
   - GSMA 标准 eSIM 激活码格式为 `LPA:1$<SM-DP+>$<Activation_Code>`。
   - 很多用户在 PC / 平板端打开看板，如果能直接展示二维码，即可用手机相机或系统蜂窝网络设置直接扫描添加。
2. **多币种汇总与本位币换算**：
   - 数字游民和海淘订阅用户往往同时持有 USD（ChatGPT/Midjourney）、TRY（YouTube/Spotify）、HKD、EUR 等订阅。
   - 纯粹的多币种平铺无法直观了解自己每个月“总共花了多少人民币/美元”。
3. **订阅自动续期与免维护**：
   - 话费类型已实现扣费日自动扣减（`auto-deduct.js`）。
   - 订阅类型标记了 `autoRenew`，应同理在到期日当天由 Cron 自动更新 `expireDate`，真正实现“设置一次，终身免手动点续期”。

### 2.3 安全与稳定性

1. **API 限流加固**：
   - `/api/auth/send` 需限制单 IP 1分钟内只能请求 1 次，5分钟内最多 3 次，防止恶意刷接口。
2. **脱敏保护**：
   - eSIM 激活码（Activation Code）、确认码（Confirmation Code）及 WID 属高敏感资产凭证，在前端应默认脱敏遮罩，点击时才显示。
